# Morris Worm (1988) — Cyber Security Case Study

Academic case-study deliverables on the **Morris Worm — 1988 Cyber Attack**.

## Files

- **Morris-Worm-1988-Case-Study.pptx** — 14-slide presentation (dark cybersecurity
  theme, cyan accents). Title → environment → what it was → release → how it worked →
  vulnerabilities → why it spread → impact → detection/response → legal & significance →
  lessons → then vs today → conclusion → references. Full speaker notes are embedded in
  each slide's Notes pane.
- **Morris-Worm-1988-Case-Study-Report.docx** — detailed academic report (abstract,
  index, 20 content sections, a slide-by-slide presenter guide, and references).

## Sources & accuracy

Historical facts are drawn from authoritative sources (FBI; Spafford 1989;
Eichin & Rochlis 1989; U.S. GAO IMTEC-89-57; *United States v. Morris*, 928 F.2d 504;
CERT/CC; Computer History Museum). The "then vs today" comparison is present-day
analysis and is labelled as such. Numeric figures (≈6,000 systems, ~10% of ~60,000,
cost estimates) are contemporary estimates, not an exact census.
